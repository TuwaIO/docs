# API Reference

The endpoints of the Quasar API that [`@tuwaio/quasar-sdk`](https://sdk.docs.tuwa.io/packages/quasar-sdk) calls. Quasar Cloud serves them at `https://api.tuwa.io`, a self-hosted node at its own URL. Authenticate with the secret key of your app in the `x-tuwa-secret-key` header, from your server only (see [Apps & Keys](/quasar/apps-and-keys)).
