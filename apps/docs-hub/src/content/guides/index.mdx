# Architecture Blueprints & Deep Dives

While individual package documentation provides granular, function-level API references, this hub is dedicated to **high-level Web3 architecture, production battle-testing, and real-world execution recipes**.

We do not write generic "Hello World" tutorials. Web3 engineering collapses when real-world blockchain mechanics meet naive frontend code: mempool congestion, fee spikes, dropped nonces, speed-ups, tab switching, and component unmounting. The blueprints documented here solve these non-trivial problems using local-first, headless, and self-custodial architectural patterns.

## Architectural Principles

Every blueprint in this repository adheres to three non-negotiable engineering principles:

1. **Self-Custodial & Sovereign Architecture:** Frontends operate with uncompromising self-custody—free from proprietary, closed-source Wallet-as-a-Service (WaaS) lock-in. Client applications maintain resilient local-first state, seamlessly augmented by self-hosted cloud infrastructure (Quasar) for multi-device indexing, webhook delivery, and backend orchestration without sacrificing user sovereignty.
2. **Headless Separation of Concerns:** Core logic lives in framework-agnostic state stores (`satellite`, `pulsar`, `orbit`). Presentation lives in disposable UI views (`nova`). Changes to UI styling never jeopardize underlying Web3 state machines.
3. **Strict Type Safety & Zero Bloat:** Zero tolerance for `any` types, legacy `@solana/web3.js` bundles, or bloated `ethers.js` packages. Only modern, high-performance primitives (`viem`, `@solana/kit`).
