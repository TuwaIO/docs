# Architecture Blueprints & Deep Dives

While individual package documentation provides granular, function-level API references, this hub is dedicated to **high-level Web3 architecture, production battle-testing, and real-world execution recipes**.

Web3 engineering fails when distributed ledger realities meet naive frontend assumptions: mempool congestion, dynamic gas spikes, dropped nonces, speed-up replacements, background tab throttling, and component unmounting. The blueprints documented here resolve these systemic issues using local-first, headless, and self-custodial architectural patterns.

## Architectural Principles

Every blueprint in this repository adheres to three non-negotiable engineering principles:

1. **Self-Custodial & Sovereign Architecture:** Frontends operate with uncompromising self-custody—free from closed-source, proprietary Wallet-as-a-Service (WaaS) lock-in. Client applications maintain resilient, local-first state, seamlessly augmented by managed cloud infrastructure (Quasar) for multi-device indexing, webhook delivery, and backend orchestration without sacrificing user sovereignty.
2. **Headless Separation of Concerns:** Core business logic lives in framework-agnostic stores (`satellite`, `pulsar`) and low-level protocol adapters (`orbit`). Presentation lives in disposable UI views (`nova`). Changes to UI styling never jeopardize underlying Web3 state machines.
3. **Strict Type Safety & Zero Bloat:** Zero tolerance for `any` types, legacy `@solana/web3.js` v1 bundles, or monolithic `ethers.js` packages. Only modern, tree-shakeable, high-performance primitives (`viem`, `@solana/kit`).
