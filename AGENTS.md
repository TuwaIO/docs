# 🤖 Agent Context: TUWA Docs (`docs.tuwa.io`, `@tuwaio/docs-ui`)

## 1. Project Philosophy & Goal

- **What is this?** A monorepo for the **TUWA documentation gateway**: the docs hub (`apps/docs-hub`, [docs.tuwa.io](https://docs.tuwa.io)) and `@tuwaio/docs-ui` (`packages/docs-ui`), the shared UI of every TUWA documentation site.
- **Role in TUWA:** not a code layer. The hub is where developers start: a map of the TUWA stages and projects with links to their sites, and the guides. `@tuwaio/docs-ui` is consumed by the sites of Orbit, SIWX, Satellite Connect, Pulsar and the SDK, by the hub, the landing page (`Landing/website`) and the Quasar dashboards. Nothing in the ecosystem depends on the hub.
- **Philosophy:** one place per kind of content.
  - `docs.tuwa.io` (this repo): the ecosystem map, the guides — architecture deep dives and step-by-step setups that combine several TUWA projects — and the Quasar docs (`/quasar`: Quasar Cloud and the self-hosted Community Edition, with the API reference).
  - `*.docs.tuwa.io` (the project repos): an Introduction, the package READMEs and a reference of every export generated by TypeDoc, plus scenarios of a single package.
  - `stories.tuwa.io` (`nova-uikit`): the Nova UI Kit components, theming and package reference in Storybook.

## 2. Tech Stack (Verified)

- **Core:** TypeScript 6.0.3 (pinned exactly in the root, `apps/docs-hub` and `packages/docs-ui` `package.json`), pnpm 12 (`packageManager`, workspace).
- **`apps/docs-hub`:** Next.js 16 (App Router), Nextra 4 (`nextra`, `nextra-theme-docs`) for `/guides`, Tailwind CSS v4 with PostCSS, `next-themes`, `nextjs-toploader`, `@heroicons/react`, Pagefind (search index built after `next build`), `@tuwaio/nova-core` (design tokens, `useCopyToClipboard`), `@tuwaio/docs-ui` (`workspace:*`, **injected**: pnpm copies it into the dependency context of the hub, so it uses the hub's copies of `next` and `nextra-theme-docs`; `syncInjectedDepsAfterScripts: [build]` refreshes the copy after `pnpm build`), `@scalar/api-reference-react` (the Quasar API reference, client only; `vue-demi` builds are disabled in `pnpm-workspace.yaml`). `pnpm-workspace.yaml` pins `zod` 4.3.6 for `nextra` and `nextra-theme-docs`: their `Layout` rejects its own props with zod 4.4 and newer, which Scalar requires.
- **`packages/docs-ui`:** `tsup` without bundling (`bundle: false`, ESM/CJS/DTS, one output file per source file) and PostCSS with `@tailwindcss/postcss` for `dist/index.css`. Dependencies: `@tuwaio/nova-core` (`cn`, and the `--tuwa-*` variables inlined into `dist/index.css` at build time), `clsx` and `tailwind-merge` (peers of `@tuwaio/nova-core`), `html-react-parser`. Peers: `react` (`>=19.2.3`), `next` (`>=16.1`, `RemoteLogo` is a Server Component using the Next.js `fetch` cache), `nextra-theme-docs` (`>=4.6`), `@heroicons/react` (`>=2`).
- **Testing:** none in this repo; verify with `pnpm build`, `pnpm build:hub` and `pnpm lint`.
- **Build/Release:** `release-please` (stable releases of `@tuwaio/docs-ui` from `main`) and `semantic-release` (`alpha.release.config.js`, prereleases). The hub is deployed by Vercel from `main`.

### Module Breakdown

- **Main screen of the hub:** `LayerTimeline` lists the TUWA stages and projects (`layers` of `src/lib/ecosystem.ts`: name, tagline, packages with their layer L1–L9, `docsUrl`, `githubUrl`) with release badges (`getReleases`). Hovering an npm package shows `PackagePreview`; a click opens `PackageDialog` (the `Dialog` of `@tuwaio/nova-core`) with the details from `getPackageDetails`: peers, the SDK packages that include it, the install command with its required peers (pnpm, npm, yarn or bun), the hub pages that mention it. All data comes from `scripts/build-data.mjs`, which saves it to `src/generated/` before `next dev` and `next build` (no requests at runtime, no hourly revalidation). `QuickStartSection` shows `npx @tuwaio/create-cosmos-playground` and links to the Starter Templates guide and `TUWA_AGENTS.md`.
- **Guides:** deep dives (`multi-chain-auth-siwx-caip122`, `why-web3-transaction-state-is-broken`, `erc-4337-sovereign-account-abstraction`) and setups (`react-transaction-tracking` for Pulsar in React, `full-stack-react` for a Next.js app on the TUWA SDK, `quasar-transaction-sync` for Quasar sync and history — all with EVM and Solana tabs — and `starter-templates` for the Cosmos Playground templates).
- **Quasar (`/quasar`):** overview (Cloud and Community Edition), apps and keys, quotas and limits, webhooks (incl. the local relay of the `quasar-sdk` CLI), self-hosting (links to `TuwaIO/quasar-community/docs`, no copies) and the API reference (`QuasarApiReference`, Scalar, from `public/quasar-openapi.yaml`). The `@tuwaio/quasar-sdk` reference stays on `sdk.docs.tuwa.io`. The Quasar cards of `LayerTimeline` link here.
- **Search and LLMs:** canonical URL, Open Graph and Twitter card per MDX page (`withPageMetadata`), JSON-LD (`TechArticle`, `BreadcrumbList`; `WebSite` and `Organization` on the main page), `/sitemap.xml`, `/robots.txt`, `/llms.txt` and `/llms-full.txt` (every page as Markdown and every package README), all built at build time.
- **`@tuwaio/docs-ui`:** `Navbar`/`Footer` (wrap `nextra-theme-docs`, default links `baseNavLinks`/`baseFooterLinks`), `RemoteLogo` (fetches an SVG, by default the TUWA logo on jsDelivr, cached 24 h), `ThemeSwitcher` (stateless light/dark switch), `Orb` and `PackageType`, `StarryBackground` (canvas animation), `NoSSR`, and `dist/index.css`.

### Documentation Model

- **One place per topic.** A guide in the hub combines several TUWA projects. A scenario of one package belongs on the site of that package (for example Pulsar's EVM and Solana "Trackers Standalone" pages), and an API belongs to its generated package page; guides link to them with absolute URLs (`https://<project>.docs.tuwa.io/packages/<package>`, `https://stories.tuwa.io/?path=/docs/<id>` for Nova).
- **Guides are plain MDX.** Code examples are fenced code blocks with a `filename` meta, never template strings in React components. Variants of a step (EVM / Solana) are `Tabs` from `nextra/components`; all `Tabs` groups of a page share one `storageKey` (`tuwa-guide-network`), so one choice switches every step.
- **Examples compile** against the published packages they import. After a TUWA release that changes an API used by a guide, update the guide.
- **No redirects.** A moved or removed page is deleted, and every link to it in all TUWA repositories is updated in the same change.
- New guides are registered in `src/content/guides/_meta.tsx` and get a card in `src/content/guides/index.mdx`.
- **Quasar facts come from the code** of `TuwaIO/quasar` (the Community Edition is generated from it): limits, quotas, headers, webhook payloads and retries. `public/quasar-openapi.yaml` is generated by `pnpm openapi:gen` in the `TuwaIO/sdk` checkout next to this repository; never edit it by hand.

## 4. Coding Standards (STRICT)

- **Language:** English ONLY (Code, Comments, Commits, Docs).
- **Types:** Strict TypeScript. **NO `any`**. Usage of `ts-expect-error` must be justified.
- **Styling:** `@tuwaio/docs-ui` uses Tailwind classes with the `tuwadocs:` prefix and the `--tuwa-*` variables; the hub prefers the variables (`rounded-[var(--tuwa-rounded-corners)]`, `text-[var(--tuwa-text-primary)]`) over hard-coded values.
- **Comments:** JSDoc required for **all** exports of `packages/docs-ui/src` and of `apps/docs-hub/src/lib`.
  - Must explain _inputs_ (`@param`, props), _outputs_ (`@returns`), _errors_ and _side effects_ (network requests, caches, listeners, timers).
  - Use only standard TSDoc tags; `@param` names must match the real parameters (`@param props` for components). Use `{@link X}` only for symbols exported by the same package.
  - Barrel files (`index.ts`) have no comments. Mark exports that are not part of the public API with `@internal`.
- **Package README** (`packages/docs-ui/README.md`) is the npm page: absolute URLs for all links, including the LICENSE link; document what is saved to `localStorage` (🗄️ Browser Storage) and which hosts are contacted (🌐 External Services); every code example must compile.
- **Naming:** Files `camelCase.ts` (utils, lib), `PascalCase.tsx` (components); Components/Types `PascalCase`; Functions/Variables `camelCase`.

## 5. Key Workflows

- **Build:** `pnpm build` (builds `@tuwaio/docs-ui` and refreshes its injected copy in the hub; also runs after `pnpm install`). The hub imports the built package: rebuild it after changing it.
- **Hub:** `pnpm dev:hub` (port 3000), `pnpm build:hub` (npm data + `next build` + Pagefind), `pnpm start:hub`. Keep `next` at 16.3.7: with the Vercel build adapter, 16.3.8 writes the prerendered pages outside `.next/server/app` and Pagefind fails the deployment.
- **Lint/Format:** `pnpm lint` / `pnpm lint:fix` (ESLint) and `pnpm format` (Prettier; `CHANGELOG.md`, `next-env.d.ts`, `pnpm-lock.yaml` and `quasar-openapi.yaml` are ignored).
- **Clean:** `pnpm clean` (Nukes `node_modules` and `dist` dirs).

## 6. AI Agent Behavior (Mandatory)

- **Post-Work Routine:** After generating or modifying code or content, you **MUST** run `pnpm lint:fix` and `pnpm format`, then `pnpm build` and `pnpm build:hub`. `next build` may rewrite `apps/docs-hub/next-env.d.ts`: restore it if it changed.
- **Guide Routine:** After adding or changing a guide, compile its TypeScript examples against the published packages they import and check that every link resolves.
- **`@tuwaio/docs-ui` Routine:** Before removing or renaming an export, search all TUWA repositories for its imports (the sites of Orbit, SIWX, Satellite, Pulsar, SDK, the hub, `Landing/website`, `quasar` and `quasar-community` dashboards). A package declares as peers only what it imports; check the built `dist` after changing imports.
- **Dependency Rule:** Never install new packages without explicit user permission.
- **Hallucination Check:**
  - Do **NOT** add redirects for moved or removed pages; update the links in every TUWA repository.
  - Do **NOT** copy a package README or API reference into a guide; link to the package page.
  - Do **NOT** write guide code examples as strings inside React components.
  - Do **NOT** duplicate helpers of `@tuwaio/nova-core` (`cn`, `useCopyToClipboard`) in `@tuwaio/docs-ui` or the hub; import them. Do **NOT** re-export `@tuwaio/nova-core` from `@tuwaio/docs-ui`: sites that need it depend on it themselves.
  - Do **NOT** write "zero vendor lock-in"; use verifiable wording (open source under Apache-2.0, self-hostable, no MAU-based pricing).
  - Do **NOT** claim that Quasar Community Edition supports SIWX, passkeys, multiple tenants or history export: it is single-tenant with email, password and TOTP.
  - Do **NOT** use "Iron Dome" or other internal names in the Quasar docs, and do **NOT** claim Starknet tracking: Quasar tracks EVM (incl. Safe and ERC-4337) and Solana transactions.
  - Do **NOT** document calling Quasar with the secret key from the browser: guides call it from Server Actions after checking the SIWX session.
  - Do **NOT** remove `injected` from `@tuwaio/docs-ui` in the hub or the `zod` overrides without a green `pnpm build:hub`: a second copy of `nextra-theme-docs` fails the build with `Missing ConfigContext.Provider`, and zod 4.4+ with `expected nonoptional ... at children`.
  - Do **NOT** edit `CHANGELOG.md` files (release-please writes them).
